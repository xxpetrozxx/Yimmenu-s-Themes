Make sure to back up any theme you've created.

Steps:
- Open your desired theme with notepad
- Select and copy all the lines
- Navigate to YimMenuV2's root folder (%appdata%/YimMenuV2) and open themes.json
- Select all and paste the copied lines.

OR

- Rename your desired theme to themes.json and move it into YimMenuV2's folder.
